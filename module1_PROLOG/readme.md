
📅 Project Milestones (spread across 4 weeks)
Week 1 Milestone — Knowledge Base Design

Students submit:

    Problem description
    Facts list
    Rule plan

Week 2 Milestone — Core Rules

Students implement:

    Primary inference rules
    Basic query system


Week 3 Milestone — Advanced Logic

Students add:

    Multiple rule paths
    Handling ambiguous cases
    Expanded knowledge base

Week 4 Milestone — Final Demonstration

Students present:

    Live queries
    Explanation of logic
    What they learned
