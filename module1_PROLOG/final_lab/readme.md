🏆 FINAL 4-WEEK PROJECT
Title: Build a Logic-Based Decision System

Students create a complete rule-driven system that solves a real problem.

🧠 Project Goal

Demonstrate:

    Knowledge representation
    Logical reasoning
    Real-world applicability

🎯 Project Options (students choose one)
Option 1 — Insurance Claim Advisor

Determine:

    Claim validity
    Fraud risk
    Processing priority

Option 2 — Course Planning Advisor

Determine:

    Recommended classes
    Prerequisite chains
    Graduation eligibility

Option 3 — Game Recommendation Engine

Determine:

    Game suggestions based on preferences
    Genre logic
    Constraints

Option 4 — Network Troubleshooting Expert System

Very relevant to Balerica world 🙂

Determine:

    Root cause of network issues
    Suggested fixes
    Severity classification
