🎓 Balerica 8-Week COBOL Plan (Card-Centered Learning)

Goal at end: Student can hold a punch card and explain what every column does.

🧭 OVERALL LAB ARC

| Week | Lab Theme           | Core Skill         |
| ---- | ------------------- | ------------------ |
| 1    | Card Anatomy        | Column discipline  |
| 2    | Hello, Structure    | Divisions          |
| 3    | Data as Description | PIC clauses        |
| 4    | Movement & Math     | MOVE, ADD, COMPUTE |
| 5    | Decisions           | IF logic           |
| 6    | Loops & Control     | PERFORM            |
| 7    | File Processing     | Sequential files   |
| 8    | Mini Batch System   | Full integration   |



📅 WEEK 1 — “What Is COBOL Really?”
Focus:

Historical context + mental model.

Goals:

    Business computing origins
    Batch processing
    Why COBOL was invented
    Data processing mindset

Activity:

    Students examine a punch card.

Learn:

    80 columns
    Row/column punching
    Numeric encoding

No coding yet.


📅 WEEK 2 — Punch Card Anatomy
The MOST important week.

The classic COBOL column layout:

| Columns | Meaning                          |
| ------- | -------------------------------- |
| 1–6     | Sequence numbers                 |
| 7       | Continuation / comment indicator |
| 8–11    | Area A                           |
| 12–72   | Area B                           |
| 73–80   | Identification                   |



Students must memorize this.

Homework:

    Label a printed card diagram.

They literally annotate:

    Where code begins
    Where comments go
    What Area A vs B is


📅 WEEK 3 — Writing Your First COBOL Statements

Now introduce:

    IDENTIFICATION DIVISION
    PROGRAM-ID
    Basic DISPLAY statements

Students write on paper first in card format.

Example:

    000100 IDENTIFICATION DIVISION.
    000200 PROGRAM-ID. HELLO.
    000300 PROCEDURE DIVISION.
    000400     DISPLAY "HELLO".
    000500     STOP RUN.


📅 WEEK 4 — Data Division Basics

Teach:

    DATA DIVISION
    Working storage
    Variable declarations
    PIC clauses

This is where they see:

    COBOL is about describing data.

📅 WEEK 5 — Simple Logic

Introduce:

    MOVE
    ADD
    IF statements

Students simulate:

    Payroll calculations
    Simple business logic

Still write in card layout.

📅 WEEK 6 — File Processing Concepts

Teach conceptually (not deep):

    Sequential files
    Records
    Batch processing

Use analogies:

    Stack of cards = file
    One card = record

Very intuitive.

📅 WEEK 7 — Running Real COBOL

Now introduce actual compiler:

    GnuCOBOL
    VS Code environment

Students type programs they previously wrote on cards.


📅 WEEK 8 — The Punch Card Mastery Challenge
Final Requirement:

Each student receives a blank card template.

They must:

1️⃣ Write a valid COBOL program in card format
2️⃣ Explain orally:

    What each column means
    Why syntax placement matters
    What each division does
    
3️⃣ Demonstrate program logic

This is extremely powerful assessment.

🏆 Final “Physical Homework” Idea

    “Hold Up the Card Defense”

Students must:

    Hold their card
    Explain line by line
    Describe column usage

It becomes almost ceremonial.

💡 Extra Powerful Lesson

Troubleshoot

    One “damaged” card
    With a column shifted

Ask:

    Why would this break the program?

This drives home column sensitivity instantly.

🧠 What Students Will Gain After 8 Weeks

They will understand:

    Structured programming discipline
    Data layout importance
    Why legacy systems still work
    How enterprise logic evolved

This is rare knowledge today.
